# Spørringer mot Data Lake (Compass)

Én spørring per fil, `<navn>.sql`, med en kommentar øverst om formål, eier og dato. I Compass skrives M3-kolonner uten tabellprefiks, for eksempel `ITNO`, ikke `UCITNO`.

Planlagt i fase 3: leveranser til DESADV-partnere sammenholdt med sendte meldinger.

Tabellnavn for CRS945, CRS949 m.fl. finnes i M3 Metadata Publisher eller Data Catalog. I POC-en holder det å eksportere listene fra H5 til `../uttrekk/`.
